Case Study 03

Shopify Store Grader

Free audit tool for Shopify stores — built from scratch

shopify-grader.vercel.app
Role
Design, code & product
Scope
Full-stack web tool
Timeline
2026 — Live
Node.js Serverless Vercel PageSpeed API AI Integration UI Design HTML/CSS/JS
Overview

A tool that analyzes any Shopify store from its public URL and scores it 0–100 across SEO, performance, Shopify configuration and content quality — with actionable recommendations per check. I designed the interface, wrote the scoring logic and shipped it on Vercel serverless. It exists because auditing stores by hand was slow; now the first diagnosis takes 30 seconds.

Work Delivered
Audit Engine
26 automated checks across 4 categories: on-page SEO, Core Web Vitals via PageSpeed API, Shopify configuration and content signals.
AI Analysis Layer
AI-powered evaluation of homepage copy, product descriptions and CTA effectiveness, returning structured scores and recommendations.
UI & Report Design
Score gauge, category breakdowns, expandable check details and per-check recommendations. Designed mobile-first with a token-based CSS system.
Infrastructure
Vercel serverless functions, HTML parsing with Cheerio, graceful degradation when external APIs fail. No frameworks — vanilla stack by design.
